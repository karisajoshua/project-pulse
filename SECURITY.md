# Security Policy

ProjectPulse is a defensive, read-only repository analytics project.

Do not submit real credentials, private source code, access tokens or sensitive repository contents in issues, tests or pull requests. Use synthetic fixtures.

Security reports that would expose sensitive details should be reported privately through GitHub's security reporting features when available rather than posted as a public issue.

ProjectPulse must not execute code from repositories it analyzes. Repository metadata and file indexes should be treated as untrusted input.
